## 五、详细做法

### 蒸蛋羹做法（全程核心菜品）
```
食材：鸡蛋1个、温水80ml（40°C）、盐0.5g、香菜3g、生抽2滴（可选）

1. 鸡蛋打入碗中，加温水80ml、盐0.5g
2. 筷子彻底打散（搅30下以上）
3. 过细筛滤去气泡和蛋筋（关键！决定口感是否嫩滑）
4. 盖耐热保鲜膜，牙签扎5-6孔
5. 蒸锅水开后放入，中火蒸8分钟，关火焖1分钟
6. 出锅滴生抽2滴，撒香菜碎3g

💡 蛋水比 1:1.5 最嫩，水太多不成形，太少偏硬
```

### 皮蛋瘦肉粥做法
```
食材：大米40g、瘦肉50g、皮蛋半颗、姜丝3g、香菜5g、盐0.5g

1. 大米淘洗+600ml水，大火煮开转小火煮35分钟
2. 瘦肉剁成细泥，加淀粉3g抓匀
3. 皮蛋切碎（刀蘸水防粘）
4. 粥煮至米粒开花，入姜丝和皮蛋碎煮5分钟
5. 转最小火，肉泥撒入粥面，筷子快速搅散
6. 肉变色即关火（约1分钟），加盐
7. 撒香菜碎5g

💡 肉泥不过筛版（术后第3周起）：剁细即可，不必过筛
```

### 清蒸鲈鱼做法
```
食材：鲈鱼半条(200-250g)、姜15g、葱1段、香菜10g、蒸鱼豉油8ml、油5ml

1. 鱼洗净，两面各划2刀
2. 姜片铺盘底，鱼放上面
3. 水开后入锅大火蒸8分钟
4. 关火虚蒸（闷）2分钟
5. 倒掉盘中蒸出的腥水
6. 鱼身上铺姜丝、葱丝、香菜段
7. 另起锅烧热油5ml至冒烟，均匀淋在葱姜丝上
8. 沿盘边淋蒸鱼豉油8ml（不直接浇鱼身上）

💡 判断熟度：鱼眼凸出=全熟，筷子能轻松戳透最厚处
```

### 土豆炖牛肉做法
```
食材：牛腩100g、土豆150g、胡萝卜80g、姜3片、八角半个、生抽10ml、香菜10g

1. 牛腩切2cm块，冷水下锅焯2分钟，捞出冲净
2. 砂锅+开水800ml+牛腩+姜+八角，大火煮开转小火炖1.5h
3. 土豆、胡萝卜去皮切块
4. 牛腩炖1.5h后加入土豆、胡萝卜、生抽
5. 继续炖30分钟至牛腩酥烂
6. 大火收汁2分钟
7. 撒香菜10g出锅
```

### 番茄鸡片做法
```
食材：鸡胸肉100g、番茄1个、姜丝、香菜5g、淀粉3g、油5ml、盐1g

1. 鸡胸肉斜刀切薄片，加淀粉3g+水5ml抓匀
2. 番茄顶部划十字，开水烫30秒去皮，切小块
3. 锅烧热加油5ml，姜丝爆香
4. 入番茄块，中火炒至出汁（约3分钟），用铲子压碎
5. 加清水100ml煮开
6. 将鸡片逐片铺在番茄汤上，不要搅动
7. 盖盖中小火焖2分钟至鸡片变白
8. 轻轻翻动，加盐1g
9. 撒香菜5g出锅
```

### 生汆丸子汤做法
```
食材：前腿肉100g（瘦七肥三）、蛋清半个、淀粉8g、粉丝30g、木耳5朵、香菜15g、姜末、盐、白胡椒粉

1. 猪肉先切片→切丝→剁泥（约5分钟，剁到粘稠）
2. 肉泥+蛋清半个+淀粉8g+盐1g+白胡椒粉0.5g+姜末
3. 顺一个方向搅打5分钟至上劲（筷子立住不倒）
4. 清水800ml+姜片烧开，转最小火（水似开非开）
5. 左手虎口挤丸子，右手小勺蘸水舀入锅中
6. 丸子全部浮起后煮2分钟
7. 入泡软的粉丝和木耳，煮1分钟
8. 加盐调味，关火撒香菜15g
```

### 羊肉汤做法
```
食材：羊肉100g、白萝卜100g、姜3片、香菜20g、白胡椒粉

1. 羊肉切薄片（约2mm），冷水泡10分钟去血水
2. 白萝卜去皮切薄片
3. 锅中加水800ml+姜片烧开
4. 入羊肉片，大火煮开撇去浮沫（1分钟）
5. 入白萝卜片，转中火煮5分钟
6. 加盐1g+白胡椒粉0.5g
7. 碗底铺香菜20g，热汤冲入

💡 香菜不煮，热汤冲入激发香气，羊汤+香菜是灵魂！
```

### 通州腐乳肉做法（术后改良少酱版）
```
食材：五花肉120g、通州腐乳汁15ml、冰糖5g、黄酒10ml、姜3片、香菜5g

1. 五花肉切2cm方块，焯水2分钟捞出
2. 砂锅+五花肉+腐乳汁15ml+冰糖5g+黄酒10ml+姜+开水400ml
3. 大火煮开转小火炖1.5h
4. 筷子能轻松戳透即酥烂
5. 大火收汁至汤汁浓稠（约3分钟）
6. 出锅撒香菜5g

💡 术后版腐乳汁减半，不油腻不咸
```

### 粉蒸肉做法（术后减油版）
```
食材：五花肉120g、蒸肉米粉30g、土豆1个、生抽5ml、香菜5g

1. 五花肉切5mm厚片
2. 肉片+生抽5ml+清水10ml抓匀，腌10分钟
3. 蒸肉米粉倒入盘中，每片肉两面沾满米粉
4. 土豆去皮切厚片，铺在蒸碗底部
5. 裹好米粉的肉片码在土豆上
6. 蒸锅水开后放入，大火蒸40分钟
7. 出锅撒香菜5g

💡 术后版不额外加油，五花肉自身的油脂渗入土豆已足够香
```

### 牛肉末炖豆腐做法
```
食材：牛里脊60g、嫩豆腐200g、骨汤/清水300ml、生抽5ml、香菜10g、姜末

1. 牛肉剁成细末，加淀粉3g抓匀
2. 嫩豆腐切2cm方块
3. 锅中加骨汤300ml烧开，入姜末、生抽
4. 轻轻滑入豆腐块，中小火煮3分钟（不要翻动！）
5. 牛肉末撒入，筷子轻轻拨散
6. 再煮2分钟至牛肉变色
7. 加盐调味，勾薄芡（淀粉3g+水15ml，术后可选）
8. 撒香菜10g出锅
```

### 番茄鱼片做法
```
食材：龙利鱼100g、番茄1个、姜丝、香菜10g、淀粉3g

1. 鱼肉斜刀切5mm薄片，加淀粉3g+水5ml抓匀
2. 番茄去皮切小块
3. 锅中加少量油，姜丝爆香，入番茄炒至出汁
4. 加清水200ml煮开
5. 鱼片逐片铺入，不要搅动
6. 盖盖中小火焖2分钟至鱼片变白
7. 加盐1g，撒香菜10g
```

### 豆腐鱼片做法
```
食材：嫩豆腐200g、龙利鱼80g、姜丝、蒸鱼豉油8ml、香菜10g

1. 豆腐切1.5cm厚片铺盘底
2. 鱼肉斜刀切薄片铺在豆腐上
3. 撒姜丝，淋蒸鱼豉油+清水20ml混合液
4. 蒸锅水开入锅，大火蒸8分钟
5. 出锅撒香菜10g
```

### 清炖鸽子汤做法
```
食材：乳鸽半只、枸杞10g、黄芪5g、姜3片、香菜10g

1. 鸽子冷水焯2分钟，捞出冲净
2. 砂锅+清水800ml+鸽子+姜+黄芪，大火煮开
3. 撇浮沫，转小火炖2h
4. 最后10分钟入枸杞
5. 加盐1g，撇浮油
6. 碗底铺香菜10g，热汤冲入
```

### 火盆锅豆腐做法（改良版）
```
食材：冻豆腐100g、鲜豆腐100g、白菜100g、粉条30g、骨汤500ml、香菜10g

1. 白菜切块，冻豆腐解冻挤干水分
2. 骨汤烧开，入白菜煮3分钟至软
3. 入两种豆腐和泡软的粉条
4. 中火煮8分钟，让豆腐吸饱汤汁
5. 加盐调味，撒香菜10g

💡 炭火变灶火，灵魂是豆腐吸汤
```

### 三鲜米线做法 🍜
```
食材：米线80g、虾仁50g、瘦肉40g、木耳3朵、青菜50g、香菜15g

1. 干米线温水泡30分钟至软
2. 虾仁去虾线，瘦肉切薄片+淀粉抓匀
3. 木耳泡发切丝
4. 清水600ml烧开，入米线煮2分钟
5. 入木耳、瘦肉片、虾仁，煮1.5分钟
6. 入青菜烫30秒
7. 加盐1g+生抽3ml调味
8. 关火撒香菜15g
```

### 鸡汤米粉做法 🍜
```
食材：米粉80g、鸡腿1个、香菇3朵、姜2片、香菜15g

1. 鸡腿焯水+清水800ml+姜+香菇，大火煮开转小火炖40分钟
2. 捞出鸡腿，肉撕成丝备用
3. 米粉另起锅煮2分钟至软，捞出放碗中
4. 鸡汤加盐调味，浇在米粉上
5. 铺上鸡丝、香菇
6. 撒香菜15g
```

### 老友猪肉粉做法（术后去辣版）🍜
```
食材：米粉80g、瘦肉80g、酸笋30g、豆豉5g、蒜2瓣、香菜15g、生抽

1. 米粉温水泡软
2. 瘦肉切薄片+生抽+淀粉抓匀
3. 酸笋切丝，干锅炒2分钟去水汽（不加油）
4. 锅中加少量油，蒜末+豆豉爆香（不辣！）
5. 入酸笋翻炒1分钟，加清水600ml烧开
6. 入米粉煮2分钟
7. 肉片逐片下入，变色即熟
8. 关火，撒香菜15g（灵魂！）
```
