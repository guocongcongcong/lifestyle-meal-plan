## 饮食原则

1. **生活化：** 家常菜，正常北方饭菜少油版，不搞"减脂餐"噱头
2. **高蛋白：** 每餐必有鱼/肉/蛋/豆之一，伤口愈合需要
3. **香菜自由：** 能放香菜的都放 🌿，不设上限
4. **米粉周三周六：** 每周两次 🍜，雷打不动
5. **做法简化：** 蒸、煮、炖为主，少炒、不炸
6. **每天独立文件：** 方便修改、记录、回看
