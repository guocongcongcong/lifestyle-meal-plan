## 饮食原则

1. **生活化：** 家常菜，不搞奇奇怪怪的"减脂餐"，就是正常北方饭菜少油版
2. **高蛋白：** 每餐必有鱼/肉/蛋/豆之一，伤口愈合需要
3. **香菜自由：** 能放香菜的都放，不设上限
4. **米粉周三周六：** 每周两次米粉/米线日
5. **每日三正餐 + 可选加餐：** 不强制加餐，饿了吃酸奶/水果/坚果
6. **做法简化：** 蒸、煮、炖为主，少炒、不炸
